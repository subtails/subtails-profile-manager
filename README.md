# subtails Profile Manager

A browser extension for Chrome and Firefox that keeps your [subtails.com](https://subtails.com) account up to date
with your Steam preference record (dismissals, exclusions, wishlist) and the games you own on Epic.
It reads only under your own browser session, and the subtails page posts the data under your subtails session.

## Install

Install it from the Chrome Web Store or from Firefox Add-ons. Both links are on subtails.com under
**Profile → Settings → Steam** and **Profile → Settings → Epic**. After that it runs on its own, at most once a day,
when you visit subtails while signed in.
